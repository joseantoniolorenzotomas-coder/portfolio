La Magia de Carol

Plataforma Web Comercial & Catálogo Interactivo para Organización de Eventos y Mesas Dulces

HTML5 Semántico CSS3 Temático JavaScript Vanilla Mobile First CSP Security GitHub Pages

🎯 Visión General & Propósito del Proyecto

La Magia de Carol es un proyecto comercial real en producción desarrollado para una empresa especializada en repostería creativa, decoración y ambientación temática para eventos sociales (bodas, primeras comuniones, cumpleaños infantiles y aniversarios). El desafío consistía en crear una presencia digital artesanal y profesional que cautivara a clientes exigentes y redujera a cero la fricción en la solicitud de presupuestos, permitiendo a los usuarios visualizar ejemplos reales de montajes antes de contratar.

✨ Características & Funcionalidades Destacadas

  • Catálogo Visual Temático: Clasificación clara de propuestas decorativas con tarjetas interactivas y galería fotográfica de trabajos reales en alta resolución.
  • Canal de Reserva Directa por WhatsApp: Integración de botón flotante con codificación URI que genera un mensaje preconfigurado indicando el tipo de evento y solicitud de información sin pasos intermedios.
  • Arquitectura Mobile-First: Con más del 85% del tráfico procedente de smartphones, toda la interfaz está adaptada para interacción táctil fluida, botones de acción ergonómicos y lectura cómoda a una sola mano.
  • Seguridad y Rendimiento: Implementación estricta de Content Security Policy (CSP) en cabeceras meta para evitar vulnerabilidades de inyección y carga en menos de 1 segundo.

🛠️ Stack Tecnológico & Decisiones de Arquitectura

  • Frontend Puro (Sin Dependencias): Desarrollado íntegramente con HTML5 semántico, CSS3 modular y JavaScript ES6 nativo, garantizando máxima velocidad sin librerías pesadas.
  • Metaetiquetas Open Graph & SEO: Configuración exhaustiva de etiquetas OG (título, descripción, imagen representativa) para que al compartir el enlace por WhatsApp o redes sociales genere una previsualización atractiva.
  • Despliegue Continuo (CI/CD): Alojamiento con certificado SSL automático a través de GitHub Pages vinculado al repositorio maestro.

📈 Resultados & Estado Actual

El sitio se encuentra actualmente en producción y operativo para el público general, logrando una tasa de conversión directa hacia WhatsApp notablemente superior a la anterior presencia en redes sociales no estructurada.

DevQuest

Plataforma gratuita de aprendizaje de programación con rutas guiadas y ejercicios interactivos

Python HTML5 CSS3 JavaScript GitHub Pages

🎯 Visión General & Propósito del Proyecto

DevQuest es una plataforma web educativa que propone aprender programación mediante rutas progresivas, lecciones cortas y ejercicios interactivos. Incluye recorridos disponibles para Python, HTML, CSS, JavaScript y SQL, desde los conceptos iniciales hasta la práctica aplicada.

✨ Características & Funcionalidades Destacadas

  • Aprendizaje práctico: Rutas organizadas en lecciones y ejercicios para practicar conceptos de programación paso a paso.
  • Varios lenguajes: Contenido disponible para Python, HTML, CSS, JavaScript y SQL, con otros lenguajes indicados como próximos.
  • Progreso persistente: Guarda automáticamente el avance en el navegador, sin necesidad de registro obligatorio.
  • Gamificación: Sistema de experiencia, rachas, logros y liga para motivar la continuidad del aprendizaje.
  • Acceso gratuito y sin límite de tiempo: La plataforma no incluye anuncios y permite practicar al ritmo de cada persona.

🛠️ Stack Tecnológico & Despliegue

  • Interfaz web: HTML5, CSS3 y JavaScript para presentar las rutas y gestionar las interacciones de aprendizaje.
  • Persistencia en cliente: El progreso se conserva en el navegador del usuario.
  • Publicación: Demo desplegada y accesible públicamente mediante GitHub Pages.

Task Manager App

Sistema Integral de Productividad, Gestión de Proyectos y Sincronización en Tiempo Real

Node.js Express MongoDB JWT Auth REST API CSS Grid

🎯 Visión General & Propósito del Proyecto

Aplicación web completa diseñada para resolver la desorganización de equipos de trabajo y desarrolladores individuales. Permite planificar sprints, categorizar tareas según urgencia e impacto y monitorear el estado de entrega en tableros dinámicos.

✨ Características & Funcionalidades Destacadas

  • Autenticación y Seguridad JWT: Registro e inicio de sesión seguro con cifrado de contraseñas mediante bcrypt y validación de tokens de sesión para proteger endpoints privados.
  • Gestión Completa de Tareas (CRUD): Creación, edición, filtrado, asignación de responsables, fechas de caducidad y cambio de estados (Pendiente, En Progreso, Completada).
  • Búsqueda & Filtros Multicriterio: Filtros combinados por prioridad (Alta, Media, Baja), fechas límite y búsqueda por texto completo en tiempo real.
  • Persistencia Robusta de Datos: Modelado estructurado de colecciones en base de datos NoSQL con validaciones de esquema para integridad de datos.

🛠️ Stack Tecnológico & Decisiones de Arquitectura

  • Backend: Node.js con Express estructurado bajo arquitectura Modelo-Controlador-Ruta (MCR) para máxima escalabilidad y facilidad de testeo.
  • Base de Datos: MongoDB Atlas con ORM Mongoose para manipulación de esquemas y relaciones documentales.
  • Frontend: Interfaz reactiva con manipulación dinámica del DOM, consumo de APIs mediante async/await y almacenamiento en LocalStorage para persistencia de credenciales seguras.

Data Analytics Tool

Suite de Procesamiento de Datos, Minería Estadística y Cuadros de Mando Interactivos

Python 3 Pandas Flask NumPy Data Visualization REST API

🎯 Visión General & Propósito del Proyecto

Solución analítica concebida para automatizar el análisis cuantitativo de conjuntos de datos comerciales. Permite transformar datos en bruto (archivos de transacciones, hojas de cálculo de clientes y métricas de tráfico) en paneles visuales comprensibles para la toma de decisiones empresariales.

✨ Características & Funcionalidades Destacadas

  • Ingesta y Normalización de Archivos: Carga automatizada de archivos CSV, Excel y JSON con algoritmos de detección de tipos de datos y corrección de valores nulos o atípicos.
  • Cálculo Estadístico Avanzado: Análisis descriptivo rápido (medias, desviaciones estándar, medianas, percentiles y correlaciones de variables).
  • Visualización Dinámica: Representación gráfica de tendencias temporales, gráficos de barras y mapas de calor interactivos.
  • Exportación Consolidada: Generación de resúmenes ejecutivos listos para informes en formato estructurado.

🛠️ Stack Tecnológico & Decisiones de Arquitectura

  • Procesamiento Numérico: Biblioteca Pandas y NumPy optimizadas en Python para cálculos masivos en memoria.
  • Capa Web: Microframework Flask sirviendo una API REST ligera que comunica el backend analítico con la interfaz web.

Chat Application

Plataforma de Comunicación Instantánea Bidireccional con Salas Temáticas y Concurrencia

WebSockets Node.js JavaScript ES6 Event-Driven CSS3

🎯 Visión General & Propósito del Proyecto

Plataforma construida para dominar el paradigma de comunicación basada en eventos y arquitecturas de red concurrentes. Proporciona una sala de conversación fluida donde los mensajes se transmiten y reflejan instantáneamente entre todos los usuarios conectados sin necesidad de recargar la página web.

✨ Características & Funcionalidades Destacadas

  • Comunicación en Tiempo Real: Conexión dúplex persistente con latencia mínima para envío y recepción simultánea de mensajes.
  • Salas Temáticas de Conversación: Posibilidad de segmentar canales según equipos o temas de interés.
  • Indicadores de Actividad: Notificaciones visuales de usuarios conectados, desconexiones y estados de actividad.
  • Diseño de Interfaz Moderno: Estética similar a clientes de mensajería modernos con desplazamiento automático hacia el último mensaje recibido.

🛠️ Stack Tecnológico & Decisiones de Arquitectura

  • Protocolo: WebSockets nativo / Socket.io gestionando eventos de conexión, desconexión y difusión (broadcast).
  • Servidor Asíncrono: Node.js con bucle de eventos no bloqueante capaz de sostener múltiples conexiones simultáneas con bajo consumo de memoria.

Weather App

Aplicación Meteorológica de Precisión con Geolocalización y Adaptación Atmosférica

API REST JavaScript Vanilla Geolocation API CSS3 Animations Responsive

🎯 Visión General & Propósito del Proyecto

Aplicación de pronóstico del tiempo diseñada para ofrecer consultas rápidas y visuales. Integra geolocalización automática en el navegador para detectar el clima local de inmediato, así como un buscador mundial de ciudades.

✨ Características & Funcionalidades Destacadas

  • Detección de Ubicación Automática: Consulta de coordenadas GPS mediante la API de Geolocalización de HTML5 para mostrar el clima al instante.
  • Métricas Meteorológicas Completas: Sensación térmica, humedad relativa, presión barométrica, índice UV y velocidad del viento.
  • Previsión Extendida: Visualización de pronóstico a 5 días con temperaturas máximas y mínimas proyectadas.
  • Diseño Atmosférico Dinámico: Fondos e iconos adaptativos que varían según las condiciones actuales (soleado, lluvia, tormenta, niebla, nieve o noche).

🛠️ Stack Tecnológico & Decisiones de Arquitectura

  • Consumo de API REST: Integración mediante fetch asíncrono con control de errores por red o nombres de ciudades incorrectos.
  • Optimización de Caché: Almacenamiento en SessionStorage para evitar consultas duplicadas en periodos cortos y optimizar las cuotas de llamadas a la API.

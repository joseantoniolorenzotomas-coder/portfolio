# Instrucciones para agentes: Portfolio de desarrollador web

## Objetivo

Crear un portfolio profesional, moderno, rapido y responsive para un desarrollador web.

El portfolio debe presentar:

- Quien soy.
- Que tecnologias conozco.
- Mis proyectos.
- Enlaces a demos y codigo fuente.
- Mi experiencia o formacion.
- Formas de contacto.

El resultado debe parecer una web profesional, no una plantilla generica.

---

## Tecnologias

Usa inicialmente:

- HTML5
- CSS3
- JavaScript vanilla

No uses React, Vue, Angular, Tailwind, Bootstrap ni otras dependencias salvo que se solicite expresamente.

Prioriza código sencillo, fácil de entender y fácil de modificar.

---

## Documentación del proyecto

Mantén actualizado un archivo llamado `documentacion.md` en la raíz del proyecto.

Este archivo debe explicar de forma clara cómo está construido y cómo se utiliza el portfolio.

La documentación debe incluir estas secciones:

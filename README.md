# Portfolio Web - Jose A. Lorenzo

Portfolio profesional, moderno y responsivo para desarrollador web Full Stack (Junior).

Construido con tecnologías nativas (**HTML5**, **CSS3**, **JavaScript Vanilla**) sin dependencias pesadas.

---

## Características

- 🚀 **Rápido y ligero**: Código nativo optimizado sin sobrecarga de frameworks.
- 🎨 **Tema Oscuro Personalizado**: Paleta moderna con detalles en rojo fuego (`#ff2800`).
- 📱 **100% Responsive**: Experiencia adaptada a móviles, tablets y escritorios.
- 📜 **Visualizador de Certificados**: Modal interactivo dinámico con visualización ampliada de certificaciones.
- ✉️ **Formulario de Contacto Funcional**: Envíos directos a `joseantoniolorenzotomas@gmail.com` mediante FormSubmit con alternativa automática (`mailto:`).
- 💬 **Canales Directos**: Botón de WhatsApp integrado, enlaces a LinkedIn, GitHub, email y teléfono.

---

## Cómo abrir el proyecto

Simplemente abre el archivo `index.html` en tu navegador favorito, o ejecuta un servidor local:

```bash
# Con Python 3
python3 -m http.server 8000
```
Y visita `http://localhost:8000`.
